# Прогноз погоды на основе временных рядов

## Описание проекта

Проект представляет собой систему прогнозирования погодных условий с использованием методов анализа временных рядов. Система обучается на исторических данных и строит прогнозы на будущие периоды для различных метеорологических параметров.

## Функциональность

- **Обучение моделей**: Автоматическое обучение моделей Prophet для пяти параметров:
  - Температура (°C)
  - Скорость ветра (м/с)
  - Атмосферное давление (гПа)
  - Осадки (мм)
  - Эффективная температура (°C)

- **Прогнозирование**: Генерация прогнозов на заданный период с отображением:
  - Точечных прогнозов
  - Доверительных интервалов (для температуры)
  - Множественных параметров в единой таблице

- **Визуализация**: Вывод результатов в удобном табличном формате

## Теория временных рядов

### Основные понятия

**Временной ряд** - это последовательность данных, измеренных в последовательные моменты времени через равные промежутки.

**Компоненты временного ряда**:
- **Тренд** - долгосрочная направленная составляющая
- **Сезонность** - периодические колебания с фиксированной частотой
- **Цикличность** - колебания без фиксированной периодичности
- **Шум** - случайная составляющая

### Модель Prophet

Проект использует библиотеку Prophet от Facebook, которая основана на аддитивной модели временных рядов:

#### Основная формула Prophet

```
y(t) = g(t) + s(t) + h(t) + ε(t)
```

где:
- **g(t)** - функция тренда (кусочно-линейная или логистическая)
- **s(t)** - сезонная компонента (использует ряд Фурье)
- **h(t)** - компонента праздников и особых событий
- **ε(t)** - ошибка модели (обычно нормально распределенный шум)

#### Функция тренда

Для линейного тренда:
```
g(t) = (k + a(t)ᵀδ) × t + (m + a(t)ᵀγ)
```

где:
- **k** - базовый рост
- **δ** - вектор корректировок роста
- **m** - параметр смещения
- **a(t)** - вектор индикаторных функций

#### Сезонная компонента

Использует разложение в ряд Фурье:
```
s(t) = Σ[n=1 to N] (aₙ cos(2πnt/P) + bₙ sin(2πnt/P))
```

где:
- **P** - период сезонности (365.25 для годовой, 7 для недельной)
- **N** - количество гармоник (обычно 10 для годовой, 3 для недельной)

## Математические основы

### Метрики качества (используемые неявно)

**Mean Absolute Error (MAE)**:
```
MAE = (1/n) × Σ|y - ŷ|
```

**Mean Squared Error (MSE)**:
```
MSE = (1/n) × Σ(y - ŷ)²
```

### Оптимизация

Prophet использует **апостериорный максимум** (MAP) для оценки параметров:
```
p(θ|y) ∝ p(y|θ) × p(θ)
```

где:
- **θ** - параметры модели
- **p(y|θ)** - функция правдоподобия
- **p(θ)** - априорное распределение параметров

## Архитектура проекта

### Backend (Flask API)
- **RESTful API** для предоставления данных прогнозов
- **Интеграция с ML моделями** через pickle файлы
- **Обработка запросов** с параметрами даты и диапазона
- **Форматирование данных** в JSON для фронтенда

### Frontend (HTML/CSS/JavaScript)
- **Интерактивный интерфейс** с анимациями
- **Адаптивный дизайн** для мобильных устройств
- **Динамическое обновление** данных без перезагрузки страницы
- **Визуализация прогнозов** в таблицах и карточках

### ML Pipeline
- **Предобработка данных** из Excel файлов
- **Обучение моделей Prophet** для каждого параметра
- **Генерация прогнозов** с доверительными интервалами
- **Сериализация результатов** для быстрого доступа

## Установка и использование

### Зависимости

```bash
pip install -r requirements.txt
```

Требуемые пакеты:
- `flask` - веб-фреймворк
- `pandas` - обработка данных
- `prophet` - модели временных рядов
- `openpyxl` - чтение Excel файлов
- `requests` - HTTP запросы к внешним API

### Обучение моделей

```bash
python train.py
```

### Запуск веб-приложения

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

### API Endpoints

- `GET /api/weather` - текущая погода (через Open-Meteo API)
- `GET /api/forecast?date=YYYY-MM-DD&days=N` - прогноз на N дней
- `GET /` - главная страница с интерфейсом

### Настройка прогноза 
В серверной части можно получить прогноз:
 - В файле `app.py` измените параметры вызова:

```python
print_forecast_for_period('2025-09-20', 7)  # Дата начала и количество дней
```

## Особенности реализации

### Backend особенности
1. **Двухэтапная архитектура**: ML модели + REST API
2. **Кэширование прогнозов**: Предварительно рассчитанные прогнозы в pickle
3. **Обработка ошибок**: Грациозная обработка отсутствующих данных
4. **CORS поддержка**: Готова для развертывания на разных доменах

### Frontend особенности
1. **Интерактивный календарь**: Выбор дат для прогноза
2. **Адаптивный дизайн**: Оптимизация для мобильных устройств
3. **Анимации**: Плавные переходы и hover-эффекты
4. **Real-time обновление**: Автоматическое обновление данных

### ML особенности
1. **Обработка осадков**: Абсолютное значение для избежания отрицательных прогнозов
2. **Пропущенные данные**: Автоматическое пропускание параметров с недостаточными данными
3. **Доверительные интервалы**: Расчет и отображение для температурных прогнозов
4. **Многомодельный подход**: Отдельные модели для каждого параметра погоды
